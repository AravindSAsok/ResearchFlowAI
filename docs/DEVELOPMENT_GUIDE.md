# Development Guide

1. Create and activate the Python 3.14 virtual environment.
2. Install requirements.txt.
3. Copy .env.example to .env and configure OPENROUTER_API_KEY.
4. Start FastAPI with uvicorn app.main:app --reload.
5. Start Streamlit in a second terminal with streamlit run frontend/streamlit_app.py.
6. Upload a PDF in Document Library.
7. Ask questions in AI Chat or generate a multi-question report in Research Workspace.
8. Run tests with pytest -q.

Keep credentials in .env. Never commit .env, uploaded PDFs, Chroma data or SQLite runtime data. Local embeddings are generated by Chroma's bundled ONNX embedding function.
